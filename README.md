# EMS Tools test builds

Installable Android test builds of EMS Tools, an app for EMS field providers
with a dosage calculator, a drip rate calculator and a cardiac-arrest timer.

These are pre-release builds for invited testers. The app is a calculation aid,
not a clinical reference: check every result against your own protocols.

[Download the newest build](https://github.com/overona/ems-tools-builds/raw/main/ems-tools.apk)
and open the file on an Android phone or tablet. `ems-tools.apk` in this
repository is always the latest build; the commit history lists what changed.
